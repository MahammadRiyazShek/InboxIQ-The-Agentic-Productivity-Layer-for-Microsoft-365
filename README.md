# InboxIQ — The Agentic Productivity Layer for Microsoft 365
InboxIQ is an autonomous multi-agent assistant that lives inside Microsoft 365 and gives knowledge workers back the 2.5 hours per day they lose to email triage, status reporting, and meeting prep.  PROBLEM: Knowledge workers receive 120+ emails and 40+ Teams messages daily. They spend 2.5 hrs/day triaging, 45 min/day writing status updates, and 30 min/day prepping for meetings. Existing tools (Outlook rules, single-shot Copilot summaries) are reactive and single-task. There is no autonomous agent that owns the full inbox-to-action loop.  OBJECTIVE: Build a production-grade agentic system on the Microsoft AI Stack that reads, classifies, summarizes, drafts, schedules, and follows up on all inbound communication — turning chaos into a single morning briefing and a clean action queue.  METHODOLOGY: A six-agent swarm (Planner, Classifier, Drafter, Scheduler, Critic, Reporter) orchestrated with AutoGen v0.4 and Semantic Kernel. Azure OpenAI GPT-4o handles reasoning. RAG over 90 days of user correspondence (Azure AI Foundry hybrid index) grounds every reply in the user's voice. Microsoft Graph SDK provides Outlook/Teams/Calendar access. Cosmos DB persists agent memory + an immutable audit log. A Critic agent gates every outbound write against a policy DSL — defending against prompt injection and unsafe sends.  SCOPE: Closed beta with 12 internal users; benchmarked on 500 emails. Measured a 88% reduction in triage time, 42% lift in human-rated reply quality, and 118% more weekly focus hours. Deployed on Azure Container Apps with full IaC (Bicep) and an eval harness running on every PR.  KEY DIFFERENTIATORS: (1) Multi-agent — not a single-prompt Copilot. (2) RAG-grounded — replies match the user's voice, not GPT's default voice. (3) Human-in-the-loop — every write is approved. (4) Production-ready — Bicep IaC, eval harness, audit log, PII redaction, BYOK tenancy.
